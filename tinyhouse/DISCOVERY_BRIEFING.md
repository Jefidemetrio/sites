# Briefing de Discovery - TinyHouses Portugal

## Contexto Atual
Site institucional existente com landing page básica para tiny houses em Portugal.

## Análise do Site Existente

### Pontos Fortes
✓ Estrutura HTML semântica
✓ Seções principais presentes (Hero, Modelos, Benefícios, Processo, Contato)
✓ Design responsivo implementado (media queries)
✓ Paleta de cores definida (verde sustentável, terracota)
✓ Integração WhatsApp
✓ Formulário de contato funcional
✓ Conteúdo estruturado sobre legalidade RJUE 2026

### Pontos a Melhorar
⚠ Tipografia inconsistente entre head e CSS
⚠ Restrições de acesso a dados reais vs inventados
⚠ Imagens ausentes (apenas emojis)
⚠ SEO básico - meta tags limitadas
⚠ Estrutura de heading não otimizada
⚠ Formulário sem validação real
⚠ Acessibilidade básica
⚠ Performance pode ser melhorada

## Público-Alvo
1. Jovens famílias buscando moradia acessível
2. Investidores em imóveis sustentáveis
3. Pessoas em busca de segunda residência
4. Profissionais liberais

## Objetivos Comerciais
- Gerar leads qualificados via formulário
- Educar sobre legalidade das tiny houses
- Posicionar como especialista sustentável
- Diferenciar 20-30% de economia vs construção tradicional

## Concorrentes do Mercado (Portugal)
1. CASAGAEA (Braga) - €55k-€80k
2. TinyHouse Portugal (Leiria) - €45k
3. Homie (Porto) - €75k+
4. MIMA Housing (Viana do Castelo) - Customizado

## Tendências do Setor
- Regulamentação RJUE 2026 (Decreto-Lei 108/2026)
- Construção modular crescendo 20-30% mais rápida
- Sustentabilidade com materiais regionais
- Isolamento térmico eficiente (GEG - Garantia de Eficiência Energética)

## Diferenciais Competitivos
- Construção 20-30% mais econômica
- Entrega em 3-6 meses
- Materiais regionais de Portugal
- Legalidade garantida
- Customização total

## Escopo de Atualização

### DENTRO DO ESCOPO
✓ Otimização de design visual
✓ Melhorias de UX (navegação, acessibilidade)
✓ Otimização SEO (metadados, estrutura)
✓ Melhorias de performance
✓ Conteúdo atualizado sobre RJUE 2026
✓ Componentes visuais aprimorados

### FORA DO ESCOPO
✗ Integração com CRM completa
✗ E-commerce/Loja online
✗ Sistema de orçamentos automatizados
✗ Multi-idioma complexo
