# PROJECT.md - Novo Projeto Dinâmicos Simplificado

## Visão Geral
Site institucional minimalista estilo Apple para PMEs tecnológicas portuguesas.

## Domínio
dinamicos.jefi.com.br

## Objetivo Principal
Captação de leads qualificados através de:
- Ranking alto no Google (SEO técnico)
- Descoberta por agentes IA (JSON-LD estruturado)
- Conteúdo otimizado para ser apresentado por IA

## Stack Tecnológica
- Framework: Astro (HTML estático otimizado)
- Estilização: Tailwind CSS
- CMS: Directus (headless)
- Hospedagem: Vercel
- Analytics: Plausible (GDPR compliant)

## Páginas Principais
1. `/` - Home (hero, serviços preview, CTA)
2. `/servicos/` - Listagem serviços
3. `/sobre/` - Sobre a empresa
4. `/blog/` - Artigos/contéudo
5. `/contato/` - Formulário de captação

## Público-alvo
PMEs tecnológicas em Portugal (10-50 colaboradores)

## Diferencial Competitivo
Design minimalista premium (Apple-style) + SEO otimizado para algoritmos modernos (Google + IA)

## Escopo MVP (1 semana)
- Site institucional completo
- 5 páginas fundamentais
- Otimização SEO técnica
- JSON-LD para agentes IA
- Formulário de contato funcional
- Deploy em produção
