# Checklist SEO para PMEs em Portugal: Guia 2026

O SEO para 2026 não é o mesmo de 2020. Com a ascensão dos agentes de IA e mudanças no comportamento de busca, as estratégias precisam evoluir. Este checklist é prático, ação por ação.

## Core Web Vitals (Obrigatório)

- [ ] **LCP < 2.5s** - Imagem hero em WebP/AVIF
- [ ] **INP < 200ms** - Responda interações rapidamente
- [ ] **CLS < 0.1** - Estabilidade visual (reserve espaço)
- [ ] **FCP < 1.8s** - Primeiro conteúdo visível rápido

## SEO Técnico

- [ ] **HTTPS ativo** - Certificado SSL válido
- [ ] **Mobile-first** - Testar em dispositivos reais
- [ ] **XML Sitemap** - Últimas atualizações
- [ ] **Robots.txt** - Indexação correta
- [ ] **Canonical URLs** - Evitar conteúdo duplicado
- [ ] **Structured Data** - Schema markup básico

## On-Page SEO

- [ ] **Título único** por página (50-60 caracteres)
- [ ] **Meta description** persuasiva (150-160 caracteres)
- [ ] **URL limpa** - sem parâmetros desnecessários
- [ ] **H1 único** - corresponde ao title
- [ ] **Imagem alt** descritivo e SEO-friendly
- [ ] **Internal links** - 2-3 links contextuais relevantes

## Keywords e Conteúdo

- [ ] **Primary keyword** com intenção comercial
- [ ] **LSI keywords** - termos relacionados
- [ ] **Foco em cauda longa** - "solução para..." em vez de "solução"
- [ ] **Conteúdo atualizado** - revisão anual
- [ ] **E-E-A-T** - Experience, Expertise, Authoritativeness, Trustworthiness

## SEO Local (Portugal)

- [ ] **Google Business Profile** - Categoria específica
- [ ] **Nome, Endereço, Telefone** consistente
- [ ] **Diretórios portugueses** - Páginas Amarelas
- [ ] **Palavras-chave regionais** - "Lisboa", "Porto", etc.

## AEO - AI Engine Optimization

- [ ] **FAQPage schema** - Perguntas + respostas
- [ ] **Article/BlogPosting schema** - Para posts
- [ ] **Organization schema** - Na homepage
- [ ] **sameAs links** - LinkedIn, Wikipedia consistentes

## Performance

- [ ] **Impressões otimizadas** - WebP/AVIF
- [ ] **Cache configurado** - browser + CDN
- [ ] **Minificação** - CSS/JS/HTML
- [ ] **CDN próximo a Portugal** - Vercel, Cloudflare

## Conteúdo

- [ ] **Blog ativo** - pelo menos 1 post/mês
- [ ] **Conteúdo de valor** - não apenas SEO
- [ ] **Formato múltiplo** - textos, vídeos, infográficos
- [ ] **Download gratuito** - guia/checklist como lead magnet

## Métricas a Monitorizar

| Métrica | Meta |
|---------|------|
| PageRank | ≥ 3 para keywords principais |
| Tráfego orgânico | +20% trimestralmente |
| Taxa de rejeição | < 50% |
| Tempo no site | > 2 minutos |
| Conversão | ≥ 2% (formulário de contacto) |

### Perguntas Frequentes

<details>
<summary>Com que frequência devo atualizar o conteúdo SEO?</summary>
<p>O ideal é revisar e atualizar conteúdo importante a cada 6-12 meses. Pages com informações que mudam rapidamente (preços, serviços) devem ser revisadas a cada 3-6 meses.</p>
</details>

<details>
<summary>Quanto tempo leva para ver resultados no SEO?</summary>
<p>Resultados iniciais visíveis em 2-3 meses. Posições significativas em 6-12 meses. SEO é um investimento de longo prazo - sites bem feitos veem resultados após 12+ meses.</p>
</details>

<details>
<summary>Qual é a diferença entre SEO e AEO?</summary>
<p>SEO = posicionar em resultados de busca. AEO = aparecer como resposta direta em IA. Ambos são necessários hoje - SEO para Google, AEO para ChatGPT, Claude, Google AI.</p>
</details>
