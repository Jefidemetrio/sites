# Diretrizes SEO Técnico - Dinâmicos

## Checklist Inicial

### Core Web Vitals (Prioridade)
- [ ] LCP < 2,5 segundos
- [ ] INP < 200ms  
- [ ] CLS < 0,1
- [ ] Imagens hero em WebP/AVIF
- [ ] `fetchpriority="high"` no primeiro conteúdo
- [ ] Remover scripts bloqueantes

### Meta Tags Essenciais
- [ ] Title tag única por página (50-60 caracteres)
- [ ] Meta description persuasiva (150-160 caracteres)
- [ ] Canonical URLs
- [ ] Open Graph completo (Facebook/LinkedIn)
- [ ] Twitter Cards

### Estrutura de Dados (JSON-LD)
- [ ] Schema Organization (site)
- [ ] Schema LocalBusiness (se aplicável)
- [ ] BreadcrumbList em páginas internas
- [ ] Article/BlogPosting para blog posts
- [ ] FAQPage para FAQ (opcional)
- [ ] Service schema para serviços

### SEO On-Page
- [ ] URL limpa e semântica
- [ ] Heading hierarchy correta (H1 único, H2-H6 lógicos)
- [ ] Alt text descritivo em imagens
- [ ] Links internos estratégicos
- [ ] Mobile-first responsive
- [ ] Sitemap.xml gerado automaticamente
- [ ] robots.txt configurado

### AEO - AI Engine Optimization
- [ ] Conteúdo estruturado claramente
- [ ] Uso de FAQ formatado
- [ ] Dados organizacionais explícitos
- [ ] Authority signals claros
- [ ] Fontes/links confiáveis citados
- [ ] Schema markup avançado (Article, Author, Event)
