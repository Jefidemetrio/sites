# Publisilva - Site

Site profissional para Publisilva, especialista em Reclamos Luminosos em Aveiro.

## 📁 Estrutura

- `index.html` - Página principal
- `assets/` - Recursos estáticos (imagens, CSS, JS)

## 🚀 Tecnologias

- HTML5
- CSS3 com variáveis customizadas
- GSAP (GreenSock Animation Platform) para transições
- Google Fonts (Inter e Playfair Display)

## 🎨 Design

Layout moderno inspirado em agências premium, com:
- Transições suaves de entrada
- Efeitos de hover responsivos
- Design responsivo
- Paleta de ouro (d4af37) para destaque

## 📝 Conteúdo

Site focado em:
- Serviços de reclamos luminosos
- Decoração de montras e viaturas
- CNC e laser
- Sinalética
- Toldos e totens

## 🌐 Deploy

Para desenvolver localmente:
```bash
# Abrir index.html no navegador
```

Para produção:
- Hospedar em qualquer servidor web
- Requeridos apenas arquivos estáticos
