# Dinamicos - Empresa Multi-Negócios

## Objetivo
Apresentar a Dinamicos, uma empresa multi-negócios com gestão de diferentes segmentos, oferecendo apresentação tipo holding para pequenas e médias empresas portuguesas.

## Público-Alvo
Empresas portuguesas de pequeno e médio porte.

## Funcionalidades Principais
- **Apresentação multi-empresa** (modelo holding)
- Cada empresa com suas características e apresentação específicas
- **Call to Action** diferenciado conforme segmento escolhido pelo cliente
- **Funil inteligente** com conteúdo gerado por IA
- Conteúdo dinâmico baseado no perfil do usuário
- Artigos criados por IA

## Estrutura do Site
```
sites/dinamicos/

│   │   └── ai-content.js  # Integração com IA

```

## Tecnologias
- HTML5, CSS3, JavaScript ES6+
- Frameworks a definir (React/Vue opcional)
- Integração com APIs de IA (OpenAI, Claude)
- Mobile-first, responsivo
